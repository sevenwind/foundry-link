# Foundry Link

Прямое P2P-соединение мастера и игроков **Foundry VTT** без VPN, ZeroTier и платных серверов.
Мастер и игроки ставят только это приложение. Работает на macOS и Windows.

## Возможности

### Подключение
- **Без серверов и расходов.** Внешний адрес определяется через публичные STUN-серверы, соединение идёт напрямую между участниками.
- **До 11 игроков у одного мастера.** Игроков можно добавлять сразу пачкой.
- **Обмен кодами вместо аккаунтов.** Мастер отправляет игрокам один код комнаты, игроки присылают ответные коды. Вставка ответного кода и есть допуск игрока.
- **Прохождение NAT.** Пробивка с обеих сторон (UDP hole punching), показ типа NAT и понятная диагностика, если прямое соединение невозможно (симметричный NAT, CGNAT).
- **IPv6 и IPv4 одновременно.** Оба варианта пробуются параллельно, IPv6 стартует первым.
- **Подбор STUN-серверов под регионы.** Порядок серверов выбран по реальным проверкам из разных сетей (в том числе из РФ), список можно расширить.
- **Игроку достаточно браузера и приложения.** Foundry открывается по `localhost:30000` (или ближайшему свободному порту), трафик прозрачно пересылается мастеру.

### Стабильность и пинг
- Пинг, джиттер и потери измеряются отдельными QUIC-датаграммами раз в секунду, они не стоят в очереди за данными игры.
- Для мастера и игрока видны оценка качества канала («Отлично / Хорошо / Средне / Плохо»), график за последние 2 минуты, счётчик переподключений и объём трафика.
- Если связь молчит 15 секунд, канал считается мёртвым и переподключается автоматически (с нарастающей паузой).
- Постоянный порт и ключи: между запусками коды остаются прежними, пока не изменится внешний IP. Мастер автоматически «стучится» к отключившимся игрокам.
- Реальные сообщения об ошибках: «мастер ещё не добавил вас», «нет ответа от мастера, код мог измениться», «Foundry не найден на порту…».

### Безопасность
- Канал шифруется (QUIC / TLS 1.3).
- Доверие через отпечатки сертификатов, зашитые в коды: игрок проверяет мастера, мастер пускает только допущенных игроков.
- Мастер может в любой момент удалить игрока.
- Локальный интерфейс защищён токеном и проверкой адреса от чужих сайтов, слушает только `127.0.0.1`.

### Интерфейс
- Нативное окно на macOS (WKWebView), универсальное приложение для Apple Silicon и Intel.
- Веб-интерфейс в браузере на Windows, тёмная и светлая темы.
- Копирование кодов в один клик, индикаторы состояния Foundry и сети, журнал событий для диагностики.
- Закрытие окна не останавливает игру, выход через ⌘Q или кнопку «Выйти».

### Диагностика (`natcheck`)
Отдельная утилита для macOS и Windows:
- проверяет доступность STUN-серверов и определяет тип NAT;
- парный тест между двумя компьютерами: пробивает соединение и измеряет пинг, потери и стабильность за ~35 секунд;
- сохраняет отчёт, который можно отправить для разбора.

## Структура репозитория
| Папка | Что внутри |
|---|---|
| `flink/` | Новое P2P-приложение: движок на Go, веб-интерфейс, оболочка macOS, тесты |
| `natcheck/` | Утилита проверки NAT и парного теста соединения |
| `Sources/`, `windows/` | Первая версия на ZeroTier (SwiftUI для macOS и WPF для Windows), оставлена как есть |

## Быстрый старт
1. **Мастер:** запустить Foundry → «Я мастер» → отправить игрокам код комнаты → вставить присланные ответные коды.
2. **Игрок:** «Я игрок» → вставить код комнаты и имя → отправить мастеру ответный код → «Открыть Foundry».

Подробности и сборка: [`flink/README.md`](flink/README.md).

## Сборка
```sh
cd flink && ./build.sh        # нужны Go 1.23+ и Xcode Command Line Tools
go test -race ./...           # 11 игроков, обрыв, удаление, простой 30 с
```
Результат попадает в `flink/dist/`: `Foundry Link.app`, `FoundryLink-macOS.zip`, `FoundryLink-Windows.zip`.

## Статус и ограничения
- Ядро покрыто тестами (11 игроков, передача данных, переподключение, удаление, простой), гонок нет.
- Соединение между двумя реальными сетями приложением пока не проверено; пробивка NAT между сетями проверена утилитой `natcheck`.
- Windows- и Intel-сборки скомпилированы, но не запускались на реальных машинах.
- Прямое соединение невозможно, если у обеих сторон симметричный NAT или CGNAT.
- Скорость загрузки карт и картинок упирается в исходящий канал мастера.
- Голос и видео Foundry не поддерживаются.
