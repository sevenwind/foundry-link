# Foundry Link (P2P)

Прямое соединение мастера и игроков Foundry VTT без ZeroTier, VPN и платных серверов.
Мастер и до 11 игроков ставят только это приложение.

## Как пользоваться
**Мастер:** запустить Foundry → «Я мастер» → отправить игрокам *код комнаты* → вставить присланные
игроками *ответные коды* (можно несколько сразу). Вставка кода = допуск игрока.

**Игрок:** «Я игрок» → вставить код комнаты и имя → отправить мастеру *ответный код* →
когда мастер его добавит, нажать «Открыть Foundry».

После первой настройки всё переподключается само: порт и ключи сохраняются, коды остаются прежними,
пока не изменится внешний IP.

## Как это устроено
- Движок на Go (`flink`): STUN определяет внешний адрес, QUIC поверх UDP даёт шифрованный канал,
  пробивка NAT с обеих сторон. IPv6 и IPv4 пробуются одновременно, IPv6 стартует первым.
- Доверие: отпечаток сертификата хоста зашит в код комнаты, отпечаток игрока — в ответный код.
  Пускаются только допущенные игроки.
- Игрок слушает `localhost:30000` (или ближайший свободный порт), мастер пересылает трафик на локальный Foundry.
- Пинг, джиттер и потери меряются QUIC-датаграммами раз в секунду; при тишине 15 с канал
  считается мёртвым и переустанавливается автоматически.
- Интерфейс — локальная веб-страница (защищена токеном и проверкой Host), на macOS она открыта
  в нативном окне, на Windows — в браузере.

## Сборка
`./build.sh` (нужны Go 1.23+ и Xcode Command Line Tools) → `dist/`.
Тесты: `go test -race ./...` (11 игроков, обрыв, удаление, простой 30 с).

## Ограничения
- Прямое соединение невозможно, если у обеих сторон симметричный NAT или CGNAT. Приложение это показывает.
- Скорость загрузки карт и картинок упирается в исходящий канал мастера.
- Голос и видео Foundry не поддерживаются.
